# CardioScope — Multi-Modal Cardiovascular Risk Assessment

> Hack4Health / Byte2Beat Hackathon Submission  
> Domain: Cardiovascular Disease Prevention  
> Approach: Tabular clinical risk scoring + ECG signal anomaly detection

---

## Project Overview

CardioScope is a production-quality machine learning platform that combines two complementary engines for cardiovascular disease (CVD) risk assessment:

1. **Tabular Clinical Risk Engine** — A calibrated gradient-boosted classifier trained on 70,000 real-world patient records (Kaggle Cardiovascular Disease dataset). Produces a risk probability with SHAP-based explanations of which clinical factors are driving the prediction.

2. **ECG Signal Anomaly Detection Engine** — A 1D Convolutional Autoencoder trained on 187 usable long-duration single-lead ECG recordings. Produces a reconstruction-error-based anomaly score as a proxy for unusual rhythm patterns.

3. **Web Interface** — A dark cyberpunk / glassmorphism-themed React application exposing both models through an interactive dashboard.

## Datasets

### Dataset 1 — cardio_base.csv (Primary Training Source)
- **70,000 rows**, semicolon-delimited
- Columns: `id, age (days), gender, height, weight, ap_hi, ap_lo, cholesterol, gluc, smoke, alco, active, cardio`
- `cardio` is the binary target (CVD presence)
- **Used as canonical training source** with explicit preprocessing pipeline

### Dataset 2 — cardiac_failure_processed.csv (NOT used independently)
- Same 70,000 rows as Dataset 1, normalized `age` column
- Confirmed to be the same underlying data — concatenating would double-count
- **Excluded from training** to avoid data leakage / inflated metrics

### Dataset 3 — heart_processed.csv (Held-out validation reference)
- 918 rows, UCI Heart Failure Prediction dataset (already one-hot encoded)
- Incompatible schema — used only for qualitative comparison, not merged with Dataset 1/2

### Dataset 4 — ecg_timeseries.csv ⚠ Label Ambiguity

> **This section explicitly documents the ECG label-ambiguity resolution per competition guidelines.**

After thorough structural inspection:

| Aspect | Finding |
|--------|---------|
| Shape | 528 rows × 123,995 columns |
| Labels | **None** — no ground-truth label column exists |
| First column (`Unnamed: 0`) | Signal data, NOT patient IDs |
| Column naming | Integer indices + pandas deduplication artifacts (`.1`, `.2`, `.3` suffixes) |
| Signal layout | 5 non-contiguous column blocks forming an 87,554-sample recording per row |

**Row subsets discovered:**

| Rows | Count | Type | Used? |
|------|-------|------|-------|
| 0–186 | 187 | Clean continuous ECG, normalized [0,1] | ✅ YES |
| 187–307 | 121 | Sparse (>91% zeros, isolated samples) | ❌ NO |
| 308–527 | 220 | Quantized (discrete integer scale 1–4) | ❌ NO |

**Modeling decision:** Unsupervised 1D-CNN Autoencoder. Reconstruction error = anomaly proxy. No clinical labels assigned.

## Methods

### Tabular Clinical Risk Engine
- **Preprocessing**: Age → years, BMI = weight/(height/100)², Pulse Pressure = ap_hi − ap_lo, outlier removal (physiologically impossible BP, height, weight values)
- **Models evaluated**: Logistic Regression, Random Forest, LightGBM/GradientBoosting
- **Selection**: Best validation ROC-AUC, then Platt sigmoid calibration
- **Metrics**: Accuracy, Precision, Recall, F1, ROC-AUC, PR-AUC, Brier Score
- **Explainability**: SHAP TreeExplainer — global beeswarm + per-patient waterfall plots
- **Export**: ONNX via skl2onnx

### ECG Signal Engine
- **Architecture**: 1D CNN Autoencoder (Encoder: 3× Conv1d downsampling → 64-dim latent; Decoder: ConvTranspose1d upsampling)
- **Input**: 2000-sample windows with 1000-sample stride from 87,554-sample recordings
- **Training**: 80/20 train/val split, Adam optimizer, MSE loss, 50 epochs
- **Anomaly score**: Mean per-window MSE over all windows of a recording
- **Interpretability**: Input-gradient saliency maps
- **Export**: ONNX via torch.onnx.export

The following tabular results were produced by `notebooks/02_tabular_model.py`
with `seed=42` on the held-out 15% test split. The selected model was calibrated

|--------|-------|
| Tabular Test ROC-AUC | 0.8014 |
| Tabular Test Recall | 0.6836 |
| Tabular Test F1 | 0.7172 |
| Tabular Brier Score | 0.1811 |
| ECG Autoencoder Best Val MSE | 0.023972 |
| ECG Usable recordings | 187 / 528 (35%) |
| ECG anomaly score (mean / median / range) | 0.025832 / 0.027587 / 0.006294–0.049219 |

values are descriptive model explanations, not causal clinical effects.

## Limitations

1. **ECG is unsupervised, not diagnostic**: No validated ground-truth labels exist for `ecg_timeseries.csv`. The 1D-CNN autoencoder is trained to reconstruct 2,000-sample windows and reports reconstruction error as a relative anomaly proxy; it does not classify arrhythmia, disease, or clinical risk and has not been clinically validated.
2. **Small usable ECG sample**: Only 187/528 (35%) recordings are clean continuous waveforms. The sparse and quantized remaining 341 rows are excluded. The autoencoder validation split is recording-level (150 training / 37 validation recordings), so its MSE measures reconstruction on this small internal sample rather than clinical generalization.
3. **HRV metric inflation**: Coefficient of Variation of RR intervals is uniformly elevated due to inter-segment boundary gaps in the signal layout — not due to true clinical arrhythmia.
4. **Tabular outliers**: The raw dataset contains physiologically impossible values (e.g., negative pulse pressure, height < 100 cm). We remove these transparently, but the source of these errors is unknown.
5. **Calibration on validation set**: The Platt calibration step uses the validation set, which slightly limits independent test set interpretation.
6. **Assumed ECG sampling rate**: We infer ~250 Hz from peak spacing but cannot confirm from dataset metadata.

## Societal Impact

Cardiovascular disease is the leading cause of death globally. Early risk identification — especially in resource-constrained settings — can save lives. CardioScope demonstrates that:
- Explainable ML (SHAP) can make risk predictions actionable, not just probabilistic
- Self-supervised ECG anomaly detection can operate without expert annotations
- Open-source, reproducible pipelines lower the barrier for clinical AI research

**Ethical considerations**: This tool is NOT a replacement for clinical judgment. Any deployment would require regulatory approval, prospective validation, and equity auditing across demographic groups.

## Setup & Reproduction

### 1. Environment Setup
```bash
conda env create -f environment.yml
conda activate cardioscope
```

### 2. Place Datasets
Copy datasets to `data/`:
```
data/cardio_base.csv
data/cardiac_failure_processed.csv
data/heart_processed.csv
data/ecg_timeseries.csv
```

### 3. Run Notebooks (in order)
```bash
cd notebooks
python 01_eda_tabular.py
python 02_tabular_model.py
python 03_tabular_explainability.py
python 04_ecg_eda.py
python 05_ecg_model.py
python 06_export_onnx.py
```

### 4. Start Backend
```bash
cd backend
cp .env.example .env
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
# API docs: http://localhost:8000/docs
```

### 5. Start Frontend
```bash
cd frontend
npm install
# Optional: copy .env.example to .env and set VITE_API_URL
npm run dev
# App: http://localhost:5173
```
